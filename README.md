# EscalAgent: NetLogo Climbing Simulation #

## Introduction :  ##

Built within the second year of Master's degree in Computer Science AI specialization at Le Mans Université within the course of "Multi-Agent Systems - Embeded Systems", this project aims to provide a comprehensive simulation of agents navigating and climbing a surface. The simulation is designed to help users understand the complexities of agent-based modeling and the factors that influence agent behavior in a dynamic environment.

By leveraging the capabilities of NetLogo, a powerful multi-agent programmable modeling environment, this project allows users to visualize and analyze the interactions between agents and their environment. The simulation includes various parameters that can be adjusted to observe how changes in the environment or agent characteristics affect their climbing behavior.

## Commit convention : ##

This project follows a structured commit convention to maintain clarity and consistency in the version control history. Each commit message should adhere to the following format:


```
<type>(<scope>): <subject>
```

Where:

- `<type>`: Describes the type of change being made. Common types include:
  - `feat`: A new feature
  - `fix`: A bug fix
  - `docs`: Documentation changes
  - `style`: Code style changes (formatting, missing semi-colons, etc.)
  - `refactor`: Code refactoring without changing functionality
  - `test`: Adding or updating tests
  - `chore`: Maintenance tasks (build process, package manager, etc.)
